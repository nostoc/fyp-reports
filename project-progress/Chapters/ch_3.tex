\subsection{IPFS Off-chain Storage Integration}

The implementation of IPFS off-chain storage in the proposed system enables secure, decentralized, and efficient management of files through the use of Content Identifiers (CIDs) and distributed storage mechanisms. When a user uploads a file through the application interface, the backend service communicates with the IPFS network and adds the file to IPFS. During this process, IPFS automatically generates a unique CID based on the cryptographic hash of the file content. This CID serves as a permanent and tamper-proof reference to the uploaded file because any modification to the content results in a completely different CID. Instead of storing the entire file directly on the blockchain, only the CID and related metadata, such as file type, uploader information, and timestamps, are stored in the application database or on-chain record. This approach significantly reduces blockchain storage costs and improves scalability while still allowing files to be verified and retrieved through their associated CIDs. The actual file remains stored in a decentralized manner across the IPFS network, where multiple nodes may pin and host the content to ensure availability and fault tolerance. When a file is requested, the system retrieves it from IPFS using the CID, and the network locates the content among participating peers and delivers it while preserving integrity. Within the project architecture, the integration is managed through backend services responsible for communication with the IPFS node, while controller components handle API requests related to file uploads and retrieval operations. Additional middleware components are incorporated for file validation, request processing, and error handling to ensure reliable system functionality. The overall workflow involves uploading a file to IPFS, generating and storing the CID with metadata, and later retrieving the file from the network using the CID whenever access is required. Through this implementation, IPFS provides a reliable off-chain storage solution that combines decentralized hosting, strong integrity verification, reduced on-chain storage requirements, and efficient file management.
