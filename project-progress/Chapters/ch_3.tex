\section{AI-Based Content Moderation}

\subsection{Oracle Service Architecture}
Describe:

\begin{enumerate}
    \item relayer sends report to oracle service
    \item multiple oracle workers independently analyze content
    \item aggregator determines final moderation decision
\end{enumerate}


Mention:

\begin{enumerate}
    \item Oracle 1: toxicity classifier
    \item Oracle 2: hate/spam detection
    \item Oracle 3: rule-based relevance analysis
\end{enumerate}

\subsection{Moderation Workflow}

Describe:
\begin{enumerate}
    \item Relayer receives signed report payload.
    \item Relayer validates citizen signature and ticket.
    \item Relayer forwards report content to oracle service.
    \item Oracle workers independently classify report.
    \item Votes are aggregated.
    \item Accepted reports uploaded to IPFS.
    \item Metadata anchored on blockchain.
\end{enumerate}
